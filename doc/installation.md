# Установка и настройка

Плагин предназначен для Minishop 3.8.5. Пакет использует Plugin API 1, `ui_composition: 3` и `durable_jobs: 1`.

## Установка из пакета

1. В админке Minishop откройте «Плагины». Загрузите `minishop-blacklist-0.1.0.zip` из файлов релиза или укажите URL публичного репозитория плагина. При первой установке сверяйте открытый ключ издателя с `publisher.pub` поставки.
2. Активируйте плагин и дождитесь, пока Minishop применит пакет в веб-процессе и воркере. Воркер создаёт первый снимок настроенных источников.
3. Откройте карточку плагина и выберите «Настройки».

## Источники и отображение

- В поле «Ссылки на списки» укажите по одному публичному HTTPS-адресу на строку. Две стартовые ссылки заполнены при установке. Можно добавить до 20 источников и оставить список пустым, чтобы прекратить сопоставление.
- Интервал задаётся целым числом часов. По умолчанию это 24 часа. Новый источник будет загружен при ближайшей проверке воркера.
- Строка списка содержит Telegram ID. После первого `#` можно указать причину и ссылки. Пример с вымышленным ID и адресом доказательства

  ```text
  1000000001 # Причина совпадения https://example.org/reference
  ```

- При совпадении показываются все различающиеся комментарии. Одинаковый текст отображается один раз со всеми его ссылками. Каждая иконка ссылки открывает адрес в новой вкладке.
- Для каждого источника в настройках видны время последней попытки при ошибке, дата успешной загрузки, число уникальных Telegram ID и состояние загрузки. При сбое используется предыдущий снимок. Источник, удалённый из настроек, сразу исключается из сопоставления.
- Показ можно включить по отдельности для раздела «Пользователи из blacklist», вкладки «Чёрный список» в карточке пользователя и блока в открытом тикете. При отключении пункт меню и вкладка сохраняются в навигации, а данные скрываются. Возможности штатных списков описаны в [плане на случай расширения API](future-api.md).

## Уведомления

Укажите числовой ID чата, выдайте боту Minishop право отправлять сообщения и при необходимости задайте числовой ID топика. Оставьте поле топика пустым для отправки в чат. Отметьте события, по которым нужны уведомления. Флажок «Все» включает регистрацию, триал, оплату и истечение. При установке все события отключены.

Для регистрации проверяется привязанный Telegram ID. Для оплаты учитывается успешный платёж положительной суммы, в том числе пополнение баланса. При платном триале возможны отдельные уведомления об оплате и активации. «Истёк» совпадает с событием истечения подписки, которое публикует воркер Minishop.

## Сборка и выпуск

Сборка использует Python 3.12 и Node.js 22. Для локальной проверки с тестовым ключом выполните команды из корня репозитория в отдельном окружении Python.

```bash
python -m pip install -r requirements-build.txt
npm ci --ignore-scripts
npm run check
npm run build
npm test
python scripts/build-package.py init-key
python scripts/build-package.py build
```

Ключ создаётся один раз в `.local/publisher/minishop-blacklist.key`. Готовый пакет и индекс находятся в `dist/release`. Для повторной сборки используйте существующий ключ. Для проверки валидатором Minishop можно передать `--verify-host` в окружении, где доступны Python-модули Minishop 3.8.5.

Для выпуска настройте `MINISHOP_BLACKLIST_SIGNING_KEY` в GitHub Actions. Это постоянный приватный ключ Ed25519 в виде 32 байт, закодированных в Base64. Задание выпуска из `main` публикует архив, индекс, открытый ключ и контрольную сумму одним коммитом, затем создаёт тег `v<версия>` и GitHub Release с разделом [CHANGELOG.md](../CHANGELOG.md). При повторе опубликованный архив и тег должны совпасть с предыдущим выпуском.
