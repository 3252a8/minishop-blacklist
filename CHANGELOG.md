# Журнал изменений

## 0.2.0

- Раздел «Пользователи из blacklist» использует оформление, столбцы, поиск, сортировку и фильтры штатного списка Minishop. Причины совпадения остаются в таблице. Карточка открывается внутри админки с быстрой кнопкой возврата к результатам.
- Кнопка «Обновить списки» запускает внеплановую загрузку сохранённых источников и показывает результат по каждому из них.
- Добавлена вкладка [«Логи Telegram»](doc/telegram-diagnostics.md). В режиме отладки видны попытки отправки, параметры запроса, ответы Telegram и причины пропуска. Тестовое уведомление проверяет настроенные чат и топик.
- Исправлена проверка активации триала для случая, когда Minishop успевает обновить статус подписки до обработки уведомления.
- Добавлен [README](README.md) с обзором плагина, требованиями, установкой и настройкой.

## 0.1.0

- Добавлен плагин для Minishop 3.8.5 с двумя стартовыми источниками. Ссылки редактируются в многострочном поле, а интервал обновления задаётся в часах и по умолчанию равен 24 часам. При сбое загрузки сохраняется последний успешный снимок каждого источника.
- Добавлены раздел «Пользователи из blacklist», вкладка в карточке пользователя и статус в открытом тикете. Для одного Telegram ID отображаются все различающиеся комментарии и ссылки. Показ информации настраивается отдельно для каждого представления.
- Добавлены Telegram-уведомления о регистрации, активации триала, оплате и истечении подписки с настройкой чата, топика и набора событий.
- Добавлена сборка подписанного пакета и публикация стабильных версий через GitHub Actions. [Установка и настройка](doc/installation.md)
- Описаны [возможности будущих версий API Minishop](doc/future-api.md).
